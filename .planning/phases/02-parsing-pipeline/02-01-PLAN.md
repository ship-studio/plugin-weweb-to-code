  <action>
**src/design/parseTokens.ts** — export function `parseDesignTokens(html: string): DesignSystem`:
1. Use regex `TOKEN_REGEX = /--([0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12})\s*:\s*([^;]+);/gi` to extract all UUID-keyed CSS vars from the HTML string
2. For each match, classify using `classifyToken(value)`:
   - Font: `/^\d+\s+\d+px\/\d+px\s/` — also extract `fontSizePx` via `/\s(\d+)px\//`, `fontWeight` via `/^(\d+)\s/`, `lineHeight` via `/px\/(\d+)px/`
   - Color: `/^#[0-9a-fA-F]{3,8}$/`
   - Dimension: `/^-?\d+(\.\d+)?(px|rem|em|vh|vw|%)$/`
   - Otherwise: `'raw'`
3. Sort font tokens by `fontSizePx` descending. Assign `semanticLabel`: rank 1="h1", 2="h2", ... 6="h6", remainder="body-N"
4. Deduplicate color tokens: group by `value.toLowerCase()`, keep first occurrence per unique hex. For semantic labels: sort by lightness (parse hex to HSL), label gray-scale (saturation < 10%) as "gray-50" through "gray-900" by lightness, label highest-saturation cluster as "primary", second as "secondary", third as "accent". Keep remaining as their hex value.
5. Return `{ fonts, colors, dimensions, raw, googleFontUrls: [] }` — googleFontUrls populated by separate function

**src/design/mapFonts.ts** — export function `extractGoogleFontUrls(html: string): string[]`:
1. Use regex `/https?:\/\/fonts\.googleapis\.com\/css2[^"'\s)]+/g` to find all Google Font CSS URLs in the HTML string
2. Return unique URLs as array
3. The sample has 3 URLs: Work Sans, Open Sans, Inter
