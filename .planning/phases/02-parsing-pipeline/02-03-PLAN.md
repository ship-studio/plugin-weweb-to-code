**src/analysis/parseObjects.ts** — export functions:

`getAllWwRefs(val: unknown): string[]` — Greedy recursive finder:
1. If val is not an object or is null, return []
2. If val is an array, flatMap over elements with getAllWwRefs
3. If val is an object with `isWwObject === true` and `typeof uid === 'string'`, return `[uid]` — STOP here, do not recurse into ref
4. Otherwise, flatMap over Object.values with getAllWwRefs

`isDynamicBinding(val: unknown): val is { __wwtype: 'f' | 'js'; code: string; defaultValue?: unknown }`:
1. Check val is non-null object with `__wwtype` property equal to `'f'` or `'js'`

`buildComponentTree(section, objectMap, parentSectionIndex, libComponentRoots, visited)`:
Returns `ParsedObject[]` — the resolved tree for one section.

Internal `walkObject(uid, objectMap, visited): ParsedObject | null`:
1. If visited.has(uid), return null (cycle guard)
2. Add uid to visited
3. Get obj from objectMap[uid]; if missing, return null
4. Determine `componentType` via `lookupComponentType(obj.wwObjectBaseId, obj.name)`
5. Determine `isLibraryComponent` from `!!obj.libraryComponentBaseId`
6. Scan ALL values in `obj.content?.default ?? {}` for isDynamicBinding — set `isDynamic = true` if any found
7. Check `obj._state?.style?.default?.conditionalRendering` — if isDynamicBinding, set `conditionalRendering: '[DYNAMIC: conditional]'`; if boolean true, set `conditionalRendering: 'always visible'`
8. Extract `textContent`: if `obj.content?.default?.text` exists, check isDynamicBinding → `'[DYNAMIC]'`, else use string value
9. Extract `imageUrl`: if `obj.content?.default?.url` exists, check isDynamicBinding → `'[DYNAMIC]'`, else use string value. Skip CDN placeholders containing `cdn.weweb.app`
10. Extract breakpoint styles: `styleDefault = obj._state?.style?.default ?? {}`, `styleMobile = obj._state?.style?.mobile`, `styleTablet = obj._state?.style?.tablet`
11. Get child refs via `getAllWwRefs(obj.content?.default ?? {})` — recursively walk each to build `children: ParsedObject[]`
12. Get interactions from `obj._state?.interactions ?? []` — store raw for now (Plan 04 will linearize)
13. Return complete ParsedObject

Main `buildComponentTree` logic:
1. **Prong 1:** For each breakpoint in `section.content`, get `wwObjects` array refs. Walk each ref.uid through walkObject.
2. **Prong 2:** Get all UIDs from `parentSectionIndex.get(section.uid) ?? []`. Walk each through walkObject (handles linked/shared sections with empty content.wwObjects).
3. Return collected ParsedObject[] (from both prongs, deduped by visited set).

NOTE: Prong 3 (libraryComponent roots) is called at the PAGE level, not per-section. The caller in `parsePages.ts` (or `analyze.ts` orchestrator) should walk `libraryComponents[].rootElementId` through walkObject after all sections are processed.

Build `parentSectionIndex: Map<string, string[]>` in the caller by iterating all wwObjects: for each obj with `parentSectionId`, add obj.uid to the array for that parentSectionId key.
