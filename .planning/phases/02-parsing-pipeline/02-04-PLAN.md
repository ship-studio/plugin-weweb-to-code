**src/analysis/parseWorkflows.ts** — export functions:

`linearizeWorkflowChain(firstActionId: string | undefined, actionsMap: Record<string, unknown>): ActionSpec[]`:
1. If !firstActionId, return []
2. Walk the chain: `current = firstActionId`, loop while current exists and not visited
3. Add current to visited Set
4. Get action from actionsMap[current]; if missing, break
5. Create ActionSpec: `{ type: (action as any).type ?? 'unknown', name: (action as any).name ?? (action as any).type ?? 'unnamed' }`
6. If action.type === 'variable': extract `varId` from `(action as any).wwpiId ?? (action as any).variableId ?? (action as any).id`, look up name in variableIndex
7. For action types 'fetch-collection', 'fetch-collections', 'custom-js', 'change-page', 'if', 'switch': extract relevant details into `details` object
8. Set `current = (action as any).next` for next iteration
9. Return collected ActionSpec[]

`buildVariableIndex(variables: Array<{ id: string; name: string }>): Map<string, string>`:
1. Create Map from variable id -> name
2. Return map

`parsePageWorkflows(pageWorkflows: unknown[], pageName: string, variableIndex: Map<string, string>): WorkflowSpec[]`:
1. For each workflow in the array, create WorkflowSpec:
   - `id: wf.id`
   - `name: wf.name ?? 'unnamed workflow'`
   - `sourceType: 'page'`
   - `sourceName: pageName`
   - `trigger: wf.trigger ?? 'unknown'` — expected values: 'onload', 'page-unload'
   - `triggerCondition`: if `wf.triggerConditions` has `__wwtype`, set to `'[DYNAMIC: ${wf.triggerConditions.__wwtype}]'`
   - `actions`: call `linearizeWorkflowChain(wf.firstAction, wf.actions ?? {})`
2. IMPORTANT: Read from the `page.page.workflows` path, NOT `page.workflows` (which is always empty)

`parseElementInteractions(interactions: unknown[], elementName: string, variableIndex: Map<string, string>): WorkflowSpec[]`:
1. For each interaction, create WorkflowSpec:
   - `id: interaction.id`
   - `name: interaction.name ?? interaction.trigger ?? 'unnamed'`
   - `sourceType: 'element'`
   - `sourceName: elementName`
   - `trigger: interaction.trigger` — expected values: 'click', 'change', 'submit', 'cellValueChanged', '_wwOnMounted', 'scan', 'action', 'eventClick'
   - `triggerCondition`: if `interaction.triggerConditions` has `__wwtype`, set to `'[DYNAMIC: ${interaction.triggerConditions.__wwtype}]'`
   - `actions`: call `linearizeWorkflowChain(interaction.firstAction, interaction.actions ?? {})`

`parseVariables(rawVars: unknown[]): VariableEntry[]`:
1. Map each raw variable to VariableEntry: `{ id: v.id, name: v.name ?? 'unnamed', type: v.type ?? 'string', defaultValue: v.defaultValue ?? null, isLocalStorage: !!v.isLocalStorage, isPersistentOnNav: !!v.isPersistentOnNav }`

`parseCollections(rawColls: unknown[]): CollectionEntry[]`:
1. Map each raw collection to CollectionEntry: `{ id: c.id, name: c.name ?? 'unnamed', type: c.mode === 'single' ? 'single' : 'list', table: c.config?.table ?? '', pluginId: c.pluginId ?? '' }`
