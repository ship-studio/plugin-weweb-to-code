**src/analysis/detectShared.ts** — export function `detectSharedSections(pages: ParsedPage[]): Map<string, string>`:

1. Create `pageFreq: Map<string, Set<string>>` — maps sectionBaseId to set of pageIds
2. Create `baseTitles: Map<string, string>` — maps sectionBaseId to its title
3. For each page, for each section in page.sections:
   - Get `bid = section.sectionBaseId`; if falsy, skip
   - If not in pageFreq, add with new Set
   - Add `page.id` to the Set (NOT section.uid — we count DISTINCT pages)
   - Store title in baseTitles
4. Compute `threshold = pages.length * 0.5`
5. Create `shared: Map<string, string>`
6. For each [bid, pageIds] in pageFreq: if `pageIds.size >= threshold`, add to shared
7. Mutate pages: for each page, for each section, if `section.sectionBaseId` is in shared map, set `section.isShared = true`
8. Return shared map

**src/analysis/analyze.ts** — export async function `analyzeSite(shell: Shell, extractDir: string, entries: string[], projectPath: string, onProgress: (step: ZipStep) => void): Promise<{ siteAnalysis: SiteAnalysis; designSystem: DesignSystem; assetManifest: AssetManifest }>`:

This is the full pipeline orchestrator. Steps:

1. **Read HTML shell for design tokens:**
   - Read `${extractDir}/index.html` via `readJsonFile` pattern (base64 read, but raw string not JSON — use `shell.exec('bash', ['-c', "base64 < '${extractDir}/index.html'"])` then `atob()`)
   - Call `parseDesignTokens(html)` to get classified tokens
   - Call `extractGoogleFontUrls(html)` to get Google Font URLs
   - Merge: `designSystem.googleFontUrls = googleFontUrls`
   - Report progress: `onProgress({ kind: 'analyzing', pageCount: 0 })`

2. **Read manifest.json for site name:**
   - Read `${extractDir}/manifest.json` via readJsonFile
   - Extract `siteName = manifest.name ?? manifest.short_name ?? 'Unnamed Site'`

3. **Discover data/*.json files:**
   - Filter entries for files matching `data/*.json` pattern (not ending with `/`)
   - Extract page IDs from filenames (strip `data/` prefix and `.json` suffix)

4. **Parse each page JSON:**
   - For each page ID, read `${extractDir}/data/${pageId}.json` via readJsonFile
   - Call `parsePageData(pageJson, pageId)` to get ParsedPage
   - Report progress: `onProgress({ kind: 'analyzing', pageCount: parsedSoFar })`

5. **Build component trees for each page:**
   - For each page, for each section:
     - Build `parentSectionIndex: Map<string, string[]>` from all wwObjects in the raw page JSON (objects with `parentSectionId`)
     - Get `libComponentRoots: string[]` from `pageJson.libraryComponents[].rootElementId`
     - Call `buildComponentTree(section, objectMap, parentSectionIndex, libComponentRoots, visited)` for each section
     - Assign returned ParsedObject[] to `section.components`
   - After all sections: walk libraryComponent roots through the same walkObject (Prong 3)

6. **Parse workflows and interactions for each page:**
   - Build `variableIndex` from page variables via `buildVariableIndex(pageJson.variables)`
   - Call `parsePageWorkflows(pageJson.page.workflows ?? [], route, variableIndex)` — note: `page.page.workflows`, NOT `page.workflows`
   - For each ParsedObject in the tree (recursive), if it has `_state.interactions`, call `parseElementInteractions(interactions, objectName, variableIndex)` and assign to `parsedObject.interactions`
   - Assign page-level workflows to `parsedPage.workflows`
   - Call `parseVariables(pageJson.variables ?? [])` and assign to `parsedPage.variables`
   - Call `parseCollections(pageJson.collections ?? [])` and assign to `parsedPage.collections`

7. **Detect shared layout sections:**
   - Call `detectSharedSections(allParsedPages)`
   - This mutates `section.isShared` on each section and returns `sharedSections: Map<string, string>`

8. **Build asset manifest:**
   - Call `buildAssetManifest(entries, designSystem.googleFontUrls)`
   - Report progress: `onProgress({ kind: 'copying', label: 'Copying assets...' })`
   - Call `copyAssets(shell, extractDir, projectPath)`

9. **Aggregate and return:**
   - Deduplicate allVariables across all pages by `id`
   - Deduplicate allCollections across all pages by `id`
   - Count `totalComponentCount` by recursively counting all ParsedObjects across all pages
   - Return `{ siteAnalysis: { siteName, pages, sharedSections, allVariables, allCollections, totalComponentCount }, designSystem, assetManifest }`
