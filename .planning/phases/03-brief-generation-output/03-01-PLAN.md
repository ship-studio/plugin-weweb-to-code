    Create `src/brief/generate.ts` (~350-450 lines) with the following exported functions and internal section builders:

    **Exported:**
    - `generateBrief(input: BriefInput): BriefResult` — assembles sections, computes stats
    - `estimateTokens(markdown: string): number` — `Math.ceil(markdown.length / 4)`

    **Internal section builders (all pure functions returning string):**

    1. `buildMetadataSection(input)` — `# WeWeb Migration Brief` heading + date + stats summary line (pages, components, assets, estimated tokens)

    2. `buildMigrationPlanSection()` — `## Migration Plan` — short text explaining the migration-plan.json file will be generated and how to use it (static text, same across modes)

    3. `buildInstructionsSection(input)` — `## How to Use This Brief` — **mode-gated**:
       - pixel-perfect: "Reproduce the exact layout, spacing, and visual hierarchy. Use design tokens verbatim. Implement WeWeb interactive components (forms, tabs, sliders) as native equivalents."
       - best-site: "Use this brief as reference. Modernize with relative units, semantic HTML, and component-based architecture." Then list which preserve options are active and append customNotes as blockquote if present.

    4. `buildOverviewSection(input)` — `## Site Overview` — table of all pages with route, section count, component count, dynamic flag. Total row at bottom.

    5. `buildDesignSystemSection(ds: DesignSystem)` — `## Design System` with subsections:
       - `### Typography` table: Semantic | Size | Weight | Line Height | Token UUID (only if fonts.length > 0)
       - `### Colors` table: Semantic | Value | Token UUID (only if colors.length > 0)
       - `### Spacing & Dimensions` table: Value | Token UUID (only if dimensions.length > 0)
       - `### External Fonts` bullet list of googleFontUrls (only if non-empty)
       - Use semanticLabel as primary display, UUID as reference. Semantic first, not UUID first (per Research anti-pattern).

    6. `buildSharedLayoutSection(sa: SiteAnalysis)` — `## Shared Layout` — table of sectionBaseId and title. Returns empty string if sharedSections.size === 0. Text: "These sections appear on more than 50% of pages. Build them once as shared components."

    7. `buildPagesSection(input)` — `## Pages` — iterates `input.siteAnalysis.pages`, calls `buildPageSubsection` for each.
       - `buildPageSubsection(page, input)` — `### {route}` with dynamic flag, then for each section where `isShared === false`: section title + `renderComponentTree(section.components, 0, 3)`. Then breakpoint diffs per section (only non-empty). Then workflows.
       - `renderComponentTree(objects, depth, maxDepth)` — indented bullet list. At `depth >= maxDepth`: `- ...(N nested components)` instead of recursing. Each line: `- **{componentType}**` + `[DYNAMIC]` badge if isDynamic + `*(library)*` if isLibraryComponent + ` -- {name}` if name exists.
       - `renderBreakpointDiffs(section)` — only emit if styleMobile or styleTablet has keys. Format as key-value diff table.
       - `renderWorkflows(workflows)` — for each WorkflowSpec: trigger, action chain as numbered list.

    8. `buildAssetsSection(am: AssetManifest)` — `## Assets` with subsections:
       - `### Images` table (filename, path) if images.length > 0
       - `### Icons` table (filename, path) if icons.length > 0
       - `### Fonts` bullet list of googleFonts if non-empty
       - Summary line: "Total assets copied: {totalCopied}"

    9. `buildMigrationGuidanceSection(input)` — `## Component Migration Guidance` — table mapping common WeWeb componentType strings to recommended HTML/React equivalents. Define a `COMPONENT_MIGRATION_NOTES: Record<string, string>` lookup with entries for at least: Container/div, Text/p or span, Image/img, Button/button, Link/a, Icon/svg or icon component, Form Container/form, Input/input, Select/select, Columns/CSS grid or flexbox, Tabs/tab component, Map/map embed, Video/video element. Iterate unique componentTypes found across all pages and emit the lookup note or "Implement as custom component" fallback.

    **Helper:** `escapeTableCell(value: string): string` — replace `|` with `\|` to prevent markdown table breakage.

    **Key rules:**
    - Shared sections (isShared === true) MUST be skipped in per-page output (Research Pitfall 1)
    - Component tree depth MUST cap at 3 levels (Research Pitfall 5)
    - Breakpoint diffs MUST guard with Object.keys check (Research anti-pattern)
    - estimateTokens on FINAL assembled markdown, not per-section (Research Pitfall 2)

    Create `src/brief/generate.test.ts` with tests for the behaviors listed above. Build minimal fixture data inline (no external fixture files needed — construct SiteAnalysis/DesignSystem/AssetManifest objects with 1-2 pages, a few tokens, shared sections). Use `describe`/`it` blocks grouped by section builder.
